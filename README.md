# FreeStand × Vaseline · Demo Hub

Single-file, click-through pitch demo (`index.html`, no build step) in the same format as the Pampers India and Tide promoter demos.

**Demo 1 · Claim to loyalty (online, 36 steps)**
Set-up (audience, Mumbai → Gurugram rollout, form builder, qualification rules, pixels/embed) → Instagram Reels ad → vaseline.in landing page → WhatsApp OTP → 6 qualifying questions → eligibility + fraud checks → claim → OTP-confirmed delivery → 7-day gratification → Day-7 feedback + buy-now → **Vaseline Skin Diary** (12-week loyalty: weekly photo + 3 taps, AI-verified UGC, reel challenge, rewards, re-engagement) → analytics.

**Demo 2 · Promoter sampling (offline, 15 steps)**
Office-lobby stall (DLF Cyber City) → number or QR → promoter app → WhatsApp consent + qualify → single-use claim pass → promoter scan → hand-over → Day-7 feedback → Skin Diary on WhatsApp → promoter analytics.

Navigate with ← → keys, the Previous/Next buttons, the chapter tabs, or by clicking the phone. `#0-12` / `#1-4` in the URL deep-links to a step.

Notes
- Product name (Peptide Pro), personas and all numbers are illustrative placeholders.
- UGC/reel images are from the Vaseline Gluta-Hya × FreeStand campaign, used as stand-ins.
